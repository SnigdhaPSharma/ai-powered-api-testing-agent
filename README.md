# AI-Powered API Testing Agent

## Project Overview

A personal learning project exploring how Generative AI and AI agents can assist software quality engineering.

The application aims to analyze API specifications, generate test scenarios, execute API tests, and assist with test result analysis.

## Technology Stack

- JavaScript
- Node.js
- OpenAI API
- Express.js
- Playwright
- Zod
- Git and GitHub

## Project Status

Currently in development.
